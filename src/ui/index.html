        Boolean Filter DSL Syntax
        
      

      

        
Combine predicates with spaces (AND), OR, parentheses (...), and - (NOT):

        
    
          
  • file:src/ — match file path substring or glob (file:*.ts)
    • 
          
  • -file:test — exclude paths containing test
    • 
          
  • lang:typescript — filter by language
    • 
          
  • kind:function — filter by symbol kind
    • 
          
  • sym:/^handle/ — regex match on symbol or content
    • 
          
  • repo:name — filter by repository/context
